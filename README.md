 ## 1 기획배경
TV나 유튜브 등에서는 특정 요리를 위한 레시피를 알려주는 컨텐츠가 증가했으나, 막상 집에 있는 재료와 도구로 만들기에는 어려움. 이에 냉장고의 남은 재료로 간편하게 조리 가능한 레시피를 알려주어 실생활에 도움되는 레시피 추천 프로그램을 지식그래프를 이용하여 만들기로 했음.
